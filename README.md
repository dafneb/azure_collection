## List of content

Collection contains these tools and scripts:

- Auditing, checking and inventorying Azure resources
- Auditing, checking and inventorying Entra ID

    - Active / In-active
    - Member / Guest
    - Custom attributes
    - Licenses
    - Permissions and roles
  - Groups
    - Membership
    - Ownership
    - Permissions and roles
